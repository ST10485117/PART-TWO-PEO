## Project Overview

Isinkwa Bakery is a hypothetical artisanal bakery based in Durban, South Africa. The name "Isinkwa" means "Bread" in isiZulu, reflecting the bakery's commitment to traditional South African baking heritage. Founded in 2020 by Nomalanga Mthembu, the bakery combines time-honoured recipes with modern baking techniques to create authentic, high-quality baked goods.

This website serves as the digital storefront for Isinkwa Bakery, showcasing their products, telling their story, and providing a platform for customer engagement. The project demonstrates the practical application of web development principles, including HTML structure, responsive design, and user experience considerations.

### Website Purpose
The primary purpose of this website is to:
1. Establish a professional online presence for Isinkwa Bakery
2. Showcase the bakery's range of artisanal products
3. Share the bakery's heritage and values
4. Enable customer enquiries and orders
5. Build brand awareness and customer loyalty
